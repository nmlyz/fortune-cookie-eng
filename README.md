fortune-cookie-eng writes one fortune cookie line for a software engineer to a text file. The line was picked from 40 candidates by pairwise judging against the brief — a fortune for an engineer, funny on a first read, short and declarative, fresh, and tight with the funniest word at the end. The edge case you dismissed does not stay dismissed: it comes back with company.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run — run it twice and diff the outputs to confirm. The line is 84 characters, a single line, and ends on its strongest beat. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
